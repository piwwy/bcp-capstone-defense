## 📖 About the Project

The **BCP Alumni Management System** is a web-based platform designed to help Bestlink College of the Philippines manage, track, and engage with their alumni community. The system provides features for alumni registration, verification, event management, job postings, donation tracking, and more.

---

## 🛠 Tech Stack

| Category | Technology |
|----------|------------|
| **Frontend** | React 18, TypeScript, TailwindCSS |
| **Backend/Database** | Supabase (PostgreSQL, Auth, Storage) |
| **Build Tool** | Vite 6 |

## 🚀 Installation

### Prerequisites

- **Node.js** v18.0.0 or higher - [Download](https://nodejs.org/)
- **npm** or **yarn**
- **Git** - [Download](https://git-scm.com/)

### Setup Steps

```bash
# 1. Clone the repository
git clone https://github.com/your-username/bcp-alumni-system.git
cd bcp-alumni-system

# 2. Install dependencies
npm install

# 3. Set up environment variables (see below)
cp .env.example .env

# 4. Start development server
npm run dev

# 5. Open in browser
# http://localhost:5173
```

### Build for Production

```bash
npm run build
# Output will be in the 'dist' folder
```

## 🔑 Environment Variables

Create a `.env` file in the root directory:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```
