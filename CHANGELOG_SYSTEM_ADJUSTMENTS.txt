## DEPLOYMENT NOTES
================================================================================

IMPORTANT: The Supabase Edge Function (create-users) must be deployed:

   supabase functions deploy create-users

This function handles server-side user creation with the service role key.
Without it, the Master List Upload will only create profile records
(accounts won't be loginable).
